## 자세한 설명 (4000자)

```
IT 개발 용어와 기술 문서 영단어를 외우는 암기 앱입니다.
면접을 앞두고 "들어는 봤는데 설명을 못 하겠는" 용어를 정리하려고 만들었습니다.


■ 무엇이 들어 있나요

· IT 개발 용어 424개
  AI·에이전트 / 개발·DevOps / 아키텍처 / 보안·권한 / RAG·검색 /
  LLM 서빙 / 쿠버네티스·인프라 / 타입 계약 / LLM 평가 등 23개 분야

· IT 문서 영단어 80개
  기술 문서와 에러 메시지에 자주 쓰이는 어휘

용어마다 한국어 뜻과 영문 풀네임을 함께 담았습니다. 둘 다 정답으로 인정합니다.


■ 잊을 때쯤 다시 물어봅니다

단어마다 다음에 보여줄 날짜를 들고 있습니다.
맞히면 1일 → 3일 → 7일 → 14일 → 30일 → 60일로 간격이 길어지고,
틀리면 하루로 돌아갑니다.

모르는 것만 자주 나오고, 아는 것은 뜸해집니다.


■ 모르면 넘어가도 됩니다

찍어서 맞히면 25% 확률로 "안다"고 기록되어 그 단어가 다시 안 나옵니다.
그래서 '🤔 모르겠어요'를 따로 뒀습니다. 내일 다시 물어봅니다.


■ 틀린 것을 제대로 봅니다

결과 화면의 오답노트를 터치하면 펼쳐집니다.
뜻과 인정되는 다른 표기, 비슷한 말, 그리고
헷갈리기 쉬운 용어까지 한자리에 보여줍니다.

객관식 오답 보기는 무작위가 아닙니다.
같은 분야에서 실제로 헷갈리는 용어들로 묶었습니다.
예를 들어 'Pub/Sub'의 오답 보기는 Event-driven · Queue · Webhook 입니다.


■ 뜻을 직접 입력합니다 (영단어)

IT 문서 영단어 덱에서는 보기를 고르는 객관식뿐 아니라
뜻을 직접 써 보는 주관식도 고를 수 있습니다.

· 복수정답 인정 — 'deprecated'에 "더 이상 권장되지 않는"도 "폐기 예정인"도 정답입니다
· "비슷했어요" — 'implicit'에 "묵시적인"처럼 뜻은 통하지만 정확하지 않은 답을 따로 알려줍니다
· 대문자 자동 해제 — 영단어를 쓸 때 첫 글자가 멋대로 대문자가 되지 않습니다

한국어 의미 판정을 위해 임베딩 모델을 기기에 탑재했습니다.
표현이 달라도 뜻이 같으면 알아봅니다.


■ 인터넷이 필요 없습니다

단어도, 채점 모델도 앱 안에 있습니다.
비행기 모드에서도 모든 기능이 동작합니다.

· 회원가입이 없습니다
· 로그인이 없습니다
· 학습 기록은 이 기기에만 저장되며 외부로 전송되지 않습니다


■ 이런 분께

· 개발 직군 면접을 앞두고 용어를 정리하려는 분
· 기술 문서를 읽다 막히는 단어를 모아 두고 싶은 분
· 출퇴근길처럼 네트워크가 불안정한 곳에서 짬짬이 외우려는 분


■ 광고

결과 화면에 배너 광고 하나가 표시됩니다.
학습을 방해하지 않도록 시험 화면에는 넣지 않았습니다.

개인정보처리방침: https://reddol18.pe.kr/privacy/yongeo-hama.html
```
