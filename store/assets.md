플레이 콘솔이 요구하는 이미지와, 지금 저장소에 있는 것을 대조한다.

출처: [스토어 등록정보 만들기](https://support.google.com/googleplay/android-developer/answer/9866151?hl=ko)

## 1. 앱 아이콘 — 준비됨

| 항목 | 요구 | `store/icon-512.png` |
|---|---|---|
| 크기 | 512 × 512 | **512 × 512** ✅ |
| 형식 | 32비트 PNG (알파 포함) | Format32bppArgb ✅ |
| 파일 크기 | 최대 1,024 KB | 551 KB ✅ |

`assets/icon.png`(1024) 를 줄여 만들었다. 앱이 쓰는 원본은 그대로 둔다.

> **작은 크기에서 읽히지 않는다.** 96px 로 줄여 보면 `Python`·`개발용어`
> 같은 글자가 전부 뭉개지고 카드·책·노트북이 색덩어리가 된다. 홈 화면
> 에서 아이콘이 실제로 차지하는 크기가 그쯤이다. 교체를 검토했으나
> 지금은 두기로 했다.
>
> 바꾸게 된다면 **배경만 옅게 하는 것은 역효과**다. 하마가 보라색이라
> 배경이 옅어지면 명도 차가 줄어 더 흐려진다. 요소를 줄이는 쪽이 맞다.

### 적응형 아이콘 — 2026-11-16 수정

안드로이드 적응형 아이콘은 레이어가 108dp 인데 보이는 영역은 72dp 다.
**가운데 66.7% 만 남고 바깥 33% 는 잘린다.** 거기에 기기별 마스크
(원·사각·물방울·스퀘어클)가 한 번 더 깎는다.

**새 원본은 흰 여백이 없고 배경이 모서리까지 꽉 차 있다.**
(`assets/icon-new.png`, 1254×1254) 그래서 접근을 바꿨다.

#### 그림은 100% 그대로, 축소하지 않는다

전경 `assets/android-icon-foreground.png`(1024) 는 이렇게 만든다.

```
가운데 683px (= 1024 × 72/108)  ← 원본 100%
그 바깥 33%                      ← 같은 그림의 확대본
```

보이는 영역 안에는 **원본이 한 픽셀도 줄지 않고** 들어간다. 바깥
33% 는 어차피 잘려 나가는 자리이므로, 같은 그림을 확대해 채워
**어떤 런처 마스크에서도 배경 단색이 드러나지 않게** 한다.

#### 왜 축소를 버렸나

62%·88%·92% 로 줄인 시안을 전부 만들어 보고 기각했다.

> **축소하면 배경 파랑이 테두리처럼 보인다.** 새 원본은 모서리까지
> 그림이 차 있어서, 캔버스 가운데로 줄여 넣는 순간 둘레에 배경
> 레이어의 단색 `#4A9EFF` 가 띠처럼 남는다. 이전 원본은 흰 여백이
> 있어 이 띠가 "의도한 테두리"로 읽혔지만, 지금 원본에서는 그림이
> 액자에 갇힌 것처럼 어색하다. 그래서 축소 자체를 포기했다.

#### 남는 한계

원 마스크에서는 모서리 쪽 카드가 일부 깎인다. 이건 **원이 사각보다
작아서 생기는 기하학적 한계**지 설정으로 풀 수 있는 문제가 아니다.
그림을 줄여 맞추는 대신, 잘려도 전체 인상이 유지되는 쪽을 택했다.

#### 배경 레이어

`assets/android-icon-background.png`(512) 는 단색 `RGB(141,175,219)` 다.
실제로는 전경이 모서리까지 덮어 **보이지 않지만** 적응형 아이콘 규격이
배경 레이어를 요구하므로 둔다.

`assets/icon.png`(1024) 와 `store/icon-512.png`(512) 는 마스킹이 없으므로
**원본을 자르지 않고 100% 그대로** 리샘플만 했다.

#### 모노크롬 (테마 아이콘) — 보류

`assets/android-icon-monochrome.png`(432) 는 **손대지 않았다.**

안드로이드는 모노크롬 레이어의 **알파 채널만 읽어 시스템 틴트로**
칠한다. 그래서 휘도를 알파로 변환(어두운 선 = 불투명)해 새로 만들어
봤지만 결과가 쓸 수준이 아니었다.

| 알파 | 비율 |
|---|---|
| 불투명 (≥200) | 5.1% |
| 투명 (≤55) | 32.3% |
| **중간값** | **62.6%** |

중간값이 62.6% 라 **윤곽이 서지 않고 흐릿한 덩어리**가 된다. 미리보기
에서도 가운데 100% 영역과 바깥 확대본의 경계가 사각형 이음매로 드러나고,
카드 글자는 읽히지 않는다. 테마 아이콘은 단순한 실루엣이어야 하는데
원본 일러스트는 요소가 너무 많아 자동 변환으로는 안 된다.

**지금 기기는 테마 아이콘이 꺼져 있어 급하지 않다.** 제대로 하려면
하마 윤곽만 남긴 단색 실루엣을 따로 그려야 한다.

## 2. 그래픽 이미지 (feature graphic) — 준비됨

| 항목 | 요구 | `store/feature-graphic.png` |
|---|---|---|
| 크기 | 1024 × 500 | **1024 × 500** ✅ |
| 형식 | JPEG 또는 24비트 PNG (알파 없음) | Format24bppRgb ✅ |

스토어 상단에 걸리는 가로 배너다. **이게 없으면 등록이 진행되지 않는다.**

원본은 `assets/graphic_image.png`(1774×887). 비율이 2.000 이고 목표가
2.048 이라 위아래 12px 만 잘렸다.

> **글자를 넣지 않았다.** 이미지 생성 단계에서 한글은 거의 깨지고
> 영문도 철자가 틀리는 일이 잦다. 오른쪽에 여백이 남아 있으니
> 나중에 직접 올릴 수 있다.

## 3. 휴대전화 스크린샷 — 완료

| 항목 | 요구 | 권장 | 지금 |
|---|---|---|---|
| 개수 | 최소 2장 / 최대 8장 | **4장 이상** | 5장 |
| 형식 | JPEG 또는 24비트 PNG (알파 없음) | | `Format24bppRgb` |
| 크기 | 최소 320px, 최대 3840px<br>긴 변이 짧은 변의 2배 이내 | **1080px 이상** | 1080 × 1920 |
| 비율 | **16:9 또는 9:16** (콘솔 업로드 화면 기준) | | 9 : 16 |

### 2026-11-17 재촬영분 — `store/screenshots/` (1080px)

갤럭시 S8(SM-G950N, 1080×2220)에서 찍은 뒤 **1080×1920 으로 잘랐다.**
원본 9:18.5 는 콘솔의 9:16 조건에 맞지 않고, 긴 변이 짧은 변의 2배도
넘는다. 상태 표시줄·내비게이션 바를 잘라내고 화면마다 내용이 잘리지
않게 위치를 정했다. 자세한 경위는 `store/play-release-record.md`.
순서가 곧 스토어 노출 순서다 — 업로드하면 순서가 섞이니 콘솔에서 맞춘다.

| 파일 | 화면 | 왜 이 장면인가 |
|---|---|---|
| `01-quiz.png` | 객관식 — `pgvector`, 선택지 4개가 전부 벡터 DB 계열 | 첫인상. 무슨 앱인지 3초에 전달되고, 선택지가 다 그럴듯해 변별력이 보인다 |
| `02-correct.png` | 채점 정답 — 풀네임(`PostgreSQL에 벡터 검색을 더해 주는 확장 · pgvector`)까지 | 뜻만 맞히는 게 아니라 풀네임을 같이 준다 |
| `03-wrongnote.png` | 오답노트 — `LangGraph` 에 **내 답**(빨강)과 **정답**(초록)이 나란히, 나머지는 `🤔 모르겠어요` 배지 | 다른 단어장과 가장 다른 지점 |
| `04-start.png` | 시작 — `🔁 복습 8개 · 🌱 처음 414개` | 간격 반복을 쓴다는 신호 |
| `05-list.png` | 목록 — 분야별 묶임(`🤖 AI·에이전트 36`) | 424개의 규모와 분류가 보인다 |

**광고 없는 결과 화면을 찍었다.** 이전 기기에서는 못 했던 것인데,
S8 은 **USB adb** 라 네트워크를 꺼도 연결이 끊기지 않아 길이 열렸다.

```
adb shell svc wifi disable
adb shell svc data disable
adb shell ping -c 2 8.8.8.8   → connect: Network is unreachable
adb devices                   → 그대로 붙어 있음
```

`settings put global airplane_mode_on 1` 은 **값만 바뀌고 라디오는 안
꺼진다**(브로드캐스트가 `SecurityException` 으로 거부된다). `svc` 를
쓰는 쪽이 확실하다. 찍고 나서 `svc wifi enable` 로 되돌린다.

### 찍을 때

- **광고가 보이는 화면은 피한다.** 결과 화면을 쓸 거면 위 `svc` 로
  네트워크를 끊고 찍는다. 스토어 스크린샷에 광고가 박혀 있으면
  앱이 광고로 도배된 인상을 준다
- 상태 표시줄의 시간·배터리는 그대로 둬도 된다. 지우려면 전부 지운다
- **알파 채널 없이 저장** — `screencap` 은 32bpp 라 그대로 쓰면 안 된다.
  `Format24bppRgb` 비트맵에 다시 그려 저장한다

### adb 로 화면을 넘길 때 주의

- `adb exec-out screencap -p > out.png` 는 PowerShell 리다이렉션이
  CRLF 로 바꿔 **PNG 를 깨뜨린다.** 기기에 저장했다가 `pull` 할 것
- `adb shell input text` 는 **ASCII 만** 넣는다. 한글은 들어가지 않고
  URL 인코딩도 그대로 문자열이 된다
- `uiautomator dump` 의 이모지는 `&#129300;` **HTML 엔티티**로 나온다.
  `"🤔 모르겠어요"` 로는 안 맞고 `'모르겠어요'` 부분 매칭이라야 한다
- 화면 밖으로 밀린 버튼은 `bounds="[0,0][0,0]"` 으로 나온다. 스크롤해서
  올린 뒤에 눌러야 한다
