# 스토어 그래픽 자산 — 요구 사양과 현재 상태

플레이 콘솔이 요구하는 이미지와, 지금 저장소에 있는 것을 대조한다.

출처: [스토어 등록정보 만들기](https://support.google.com/googleplay/android-developer/answer/9866151?hl=ko)

---

## 1. 앱 아이콘 — 변환 필요

| 항목 | 요구 | 현재 |
|---|---|---|
| 크기 | **512 × 512** | `assets/icon.png` 가 **1024 × 1024** |
| 형식 | 32비트 PNG (알파 포함) | PNG |
| 파일 크기 | 최대 1,024 KB | 확인 필요 |

**할 일**: `assets/icon.png` 를 512 로 줄여 `store/icon-512.png` 로 둔다.
앱 안에서 쓰는 원본은 건드리지 않는다.

---

## 2. 그래픽 이미지 (feature graphic) — ★ 없음, 새로 만들어야 함

| 항목 | 요구 |
|---|---|
| 크기 | **1024 × 500** |
| 형식 | JPEG 또는 **24비트 PNG (알파 없음)** |

스토어 상단에 걸리는 가로 배너다. **이게 없으면 등록이 진행되지 않는다.**

지금 저장소에 1024×500 이미지가 없다. 새로 만들어야 한다.

### 만들 때

- 하마 아이콘 + 앱 이름 + 한 줄 문구
- 문구 후보: `면접에 나오는 IT 용어 424개` / `오프라인으로 외운다`
- 배경은 앱의 파랑(`#4A9EFF`)을 쓰면 아이콘·런칭 화면과 이어진다
- **글자를 가장자리에 붙이지 말 것** — 기기에 따라 잘린다. 안쪽 80% 에 둔다
- 알파 채널이 있으면 거부된다. 저장할 때 확인

---

## 3. 휴대전화 스크린샷 — ★ 해상도 미달

| 항목 | 요구 | 권장 |
|---|---|---|
| 개수 | 최소 2장 / 최대 8장 | **4장 이상** |
| 형식 | JPEG 또는 24비트 PNG (알파 없음) | |
| 크기 | 최소 320px, 최대 3840px<br>긴 변이 짧은 변의 2배 이내 | **1080px 이상** |
| 비율 | | 세로 9:16 |

### 지금 있는 것

`docs/screenshots/` 17장 중 **1080px 는 6장뿐**이다.

| 해상도 | 장수 | 파일 |
|---|---|---|
| **1080 × 2400** | 3 | `01-correct`, `02-close`, `03-ai` |
| **1080 × 2220** | 4 | `05-list`, `17-list-otherdeck`, `18-list-otherdeck-moved`, `19-list-search` |
| 720 × 1640 | 10 | 나머지 전부 |

720px 짜리도 최소 기준(320px)은 넘으므로 **등록은 된다.** 다만
구글이 "추천 콘텐츠 노출" 조건으로 1080px 이상 4장을 든다. 지금은
1080px 가 7장이라 조건 자체는 충족하지만, 그 7장이 **목록·검색 화면에
몰려 있어** 앱의 핵심인 시험·채점 화면이 빠진다.

### 다시 찍어야 할 것 (실기기, 1080px 이상)

출시용으로 고를 5장. 순서가 곧 스토어 노출 순서다.

| 순서 | 화면 | 왜 이 장면인가 |
|---|---|---|
| 1 | 객관식 문제 | 첫인상. 무슨 앱인지 3초에 전달된다 |
| 2 | 채점 — 정답 | 풀네임까지 보여주는 점이 드러난다 |
| 3 | 오답노트 펼친 상태 | 다른 단어장과 가장 다른 지점 |
| 4 | 시작 화면 (복습 개수 보이는 상태) | 간격 반복을 쓴다는 신호 |
| 5 | 목록 — 분야별 | 424개의 규모가 보인다 |

`19-list-search.png` 와 `05-list.png` 는 1080px 라 5번에 바로 쓸 수 있다.

### 찍을 때

- **광고가 보이는 화면은 피한다.** 결과 화면을 쓸 거면 광고가 안 뜬
  상태(비행기 모드)로 찍는다. 스토어 스크린샷에 광고가 박혀 있으면
  앱이 광고로 도배된 인상을 준다
- 상태 표시줄의 시간·배터리는 그대로 둬도 된다. 지우려면 전부 지운다
- 알파 채널 없이 저장

## 4. 체크리스트

```
[ ] 아이콘 512×512 로 변환          → store/icon-512.png
[ ] 그래픽 이미지 1024×500 제작      → store/feature-graphic.png
[ ] 스크린샷 5장 재촬영 (1080px+)    → store/screenshots/
[ ] 전부 알파 채널 없는지 확인
[ ] 등록정보 문안 복사               → store/listing-ko.md
[ ] 개인정보처리방침 URL 입력
[ ] 광고 포함 체크
[ ] 데이터 세이프티 — 광고 ID 수집 신고
```
