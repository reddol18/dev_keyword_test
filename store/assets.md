# 스토어 그래픽 자산 — 요구 사양과 현재 상태

플레이 콘솔이 요구하는 이미지와, 지금 저장소에 있는 것을 대조한다.

출처: [스토어 등록정보 만들기](https://support.google.com/googleplay/android-developer/answer/9866151?hl=ko)

## 1. 앱 아이콘 — 준비됨

| 항목 | 요구 | `store/icon-512.png` |
|---|---|---|
| 크기 | 512 × 512 | **512 × 512** ✅ |
| 형식 | 32비트 PNG (알파 포함) | Format32bppArgb ✅ |
| 파일 크기 | 최대 1,024 KB | 551 KB ✅ |

`assets/icon.png`(1024) 를 줄여 만들었다. 앱이 쓰는 원본은 그대로 둔다.

> **작은 크기에서 읽히지 않는다.** 96px 로 줄여 보면 `Python`·`개발용어`
> 같은 글자가 전부 뭉개지고 카드·책·노트북이 색덩어리가 된다. 홈 화면
> 에서 아이콘이 실제로 차지하는 크기가 그쯤이다. 교체를 검토했으나
> 지금은 두기로 했다.
>
> 바꾸게 된다면 **배경만 옅게 하는 것은 역효과**다. 하마가 보라색이라
> 배경이 옅어지면 명도 차가 줄어 더 흐려진다. 요소를 줄이는 쪽이 맞다.

### 적응형 아이콘 — 2026-11-16 수정

안드로이드 적응형 아이콘은 레이어가 108dp 인데 보이는 영역은 72dp 다.
**가운데 66.7% 만 남고 바깥 33% 는 잘린다.** 거기에 기기별 마스크
(원·사각·물방울·스퀘어클)가 한 번 더 깎는다.

전경이 원본 일러스트 그대로여서 실기기(Redmi, MIUI)에서 **하마 얼굴만
꽉 차게 남았다.** 왼쪽 책 더미의 `개발용어`·`암기사전`·`IT·코딩` 이
잘리고, 오른쪽 노트북은 거의 안 보이고, 위쪽 `Python` 카드도 잘렸다.

**원본을 1024 캔버스 가운데에 62% 로 축소**해 넣고 바깥은 투명하게
뒀다. 뒤는 배경 레이어(단색 `#4A9EFF`)가 채운다.
(`Format32bppArgb` — 알파가 없으면 배경이 안 보인다.)

| 비율 | 원 마스크에서 |
|---|---|
| 100% (수정 전) | 하마 얼굴만. 책·노트북·카드 전부 유실 |
| 76% | `Python` 사라짐, `개발용어` 외 책 두 권 잘림 |
| 72% | `Python` → `ython`, `IT·코딩` → `코딩` |
| 66.7% (안전 영역) | `Python` → `ython`, `IT·코딩` → `T·코딩`, `React` → `Reac` |
| **62% (채택)** | **전부 온전.** 원·사각·물방울 셋 다 잘리는 요소 없음 |

> **66.7% 로는 부족하다.** 안전 영역은 *정사각형* 기준인데 원 마스크의
> 내접 정사각형은 그 70.7% 뿐이다. 모서리 쪽 요소(`Python`, `IT·코딩`,
> `React`)가 원에서는 여전히 깎인다. 62% 가 원까지 버티는 선이다.
>
> 대신 파란 테두리가 얇게 보인다. 원본의 하늘색 배경이 `#4A9EFF` 로
> 이어져 **의도한 테두리처럼 읽힌다.** 58% 도 만들어 봤으나 위아래
> 여백이 떠 보여 버렸다.

원본은 `assets/icon-new.png`(1254×1254). `assets/icon.png` 와
`store/icon-512.png` 는 마스킹이 없으므로 **그대로 둔다.**

## 2. 그래픽 이미지 (feature graphic) — 준비됨

| 항목 | 요구 | `store/feature-graphic.png` |
|---|---|---|
| 크기 | 1024 × 500 | **1024 × 500** ✅ |
| 형식 | JPEG 또는 24비트 PNG (알파 없음) | Format24bppRgb ✅ |

스토어 상단에 걸리는 가로 배너다. **이게 없으면 등록이 진행되지 않는다.**

원본은 `assets/graphic_image.png`(1774×887). 비율이 2.000 이고 목표가
2.048 이라 위아래 12px 만 잘렸다.

> **글자를 넣지 않았다.** 이미지 생성 단계에서 한글은 거의 깨지고
> 영문도 철자가 틀리는 일이 잦다. 오른쪽에 여백이 남아 있으니
> 나중에 직접 올릴 수 있다.

## 3. 휴대전화 스크린샷 — ★ 해상도 미달

| 항목 | 요구 | 권장 |
|---|---|---|
| 개수 | 최소 2장 / 최대 8장 | **4장 이상** |
| 형식 | JPEG 또는 24비트 PNG (알파 없음) | |
| 크기 | 최소 320px, 최대 3840px<br>긴 변이 짧은 변의 2배 이내 | **1080px 이상** |
| 비율 | | 세로 9:16 |

### 지금 있는 것

`docs/screenshots/` 17장 중 **1080px 는 6장뿐**이다.

| 해상도 | 장수 | 파일 |
|---|---|---|
| **1080 × 2400** | 3 | `01-correct`, `02-close`, `03-ai` |
| **1080 × 2220** | 4 | `05-list`, `17-list-otherdeck`, `18-list-otherdeck-moved`, `19-list-search` |
| 720 × 1640 | 10 | 나머지 전부 |

720px 짜리도 최소 기준(320px)은 넘으므로 **등록은 된다.** 다만
구글이 "추천 콘텐츠 노출" 조건으로 1080px 이상 4장을 든다. 지금은
1080px 가 7장이라 조건 자체는 충족하지만, 그 7장이 **목록·검색 화면에
몰려 있어** 앱의 핵심인 시험·채점 화면이 빠진다.

### 2026-11-16 재촬영분 — `store/screenshots/` (720px)

| 파일 | 화면 |
|---|---|
| `01-quiz.png` | 객관식 — `EAI`·`ESB`·`EP`·`Gateway` 가 전부 기간계 연동 용어 |
| `02-correct.png` | 채점 정답 — 풀네임(`Enterprise Service Bus`)까지 |
| `03-start.png` | 시작 — 424개·80개·복습 9개 |
| `04-list.png` | 목록 — 분야별 묶임 |

**광고가 없는 화면만 골랐다.** 결과 화면은 배너가 박혀 있어 스토어에
쓰지 않는다. 앱만 네트워크를 끊어 광고 없는 결과 화면을 찍으려 했으나
`cmd netpolicy`·`cmd appops INTERNET` 둘 다 이 기기에서 막혔고,
무선 adb 라 비행기 모드를 켜면 연결이 끊긴다.

> **아직 720px 다.** 이 기기(Redmi 2409BRN2CL)의 화면이 720×1640 이라
> 1080px 권장을 못 맞춘다. 등록은 되지만 추천 노출 조건에서 불리하다.
> 1080px 이상 기기에서 다시 찍는 것이 남았다.

### 1080px 로 다시 찍을 때 (권장 순서)

출시용으로 고를 5장. 순서가 곧 스토어 노출 순서다.

| 순서 | 화면 | 왜 이 장면인가 |
|---|---|---|
| 1 | 객관식 문제 | 첫인상. 무슨 앱인지 3초에 전달된다 |
| 2 | 채점 — 정답 | 풀네임까지 보여주는 점이 드러난다 |
| 3 | 오답노트 펼친 상태 | 다른 단어장과 가장 다른 지점 |
| 4 | 시작 화면 (복습 개수 보이는 상태) | 간격 반복을 쓴다는 신호 |
| 5 | 목록 — 분야별 | 424개의 규모가 보인다 |

`19-list-search.png` 와 `05-list.png` 는 1080px 라 5번에 바로 쓸 수 있다.

### 찍을 때

- **광고가 보이는 화면은 피한다.** 결과 화면을 쓸 거면 광고가 안 뜬
  상태(비행기 모드)로 찍는다. 스토어 스크린샷에 광고가 박혀 있으면
  앱이 광고로 도배된 인상을 준다
- 상태 표시줄의 시간·배터리는 그대로 둬도 된다. 지우려면 전부 지운다
- 알파 채널 없이 저장

## 4. 체크리스트

```
[x] 아이콘 512×512 로 변환          → store/icon-512.png
[x] 그래픽 이미지 1024×500 제작      → store/feature-graphic.png
[~] 스크린샷 4장 확보               → store/screenshots/  (720px — 1080px 로 재촬영 권장)
[ ] 그래픽 이미지·스크린샷 알파 채널 없는지 확인 (아이콘은 알파 있어도 됨)
[ ] 등록정보 문안 복사               → store/listing-ko.md
[ ] 개인정보처리방침 URL 입력
    https://reddol18.pe.kr/privacy/yongeo-hama.html
[ ] 광고 포함 체크
[ ] 데이터 세이프티 — 광고 ID 수집 신고
```

<sub>알파 채널 규칙이 자산마다 다르다. **아이콘은 알파를 포함**하고,
그래픽 이미지와 스크린샷은 **알파가 없어야** 한다.</sub>
