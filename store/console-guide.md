## 0. 시작하기 전에 — 키스토어 백업 ★

**업로드보다 먼저 한다.** 이걸 잃으면 앱 업데이트를 영영 못 올린다.
구글도 복구해 주지 않는다. 패키지명을 바꿔 새 앱으로 올리는 수밖에 없고,
그러면 기존 설치자·리뷰·순위가 전부 날아간다.

```
E:\claude-dev\base\cedu_vocab_app\keystore\release.keystore
E:\claude-dev\base\cedu_vocab_app\.env
```

이 두 개를 **이 PC 밖으로** 복사한다 — USB, 구글 드라이브, 외장하드 중 둘 이상.
`.env` 에 키스토어 비밀번호가 들어 있으므로 같이 둬야 의미가 있다.

<sub>업로드 키를 분실해도 구글이 재설정해 주는 경로가 있긴 하다(Play App Signing
사용 시). 하지만 신청·승인에 며칠 걸리고 조건도 붙는다. 백업이 압도적으로 싸다.</sub>

## 0-2. ★ 먼저 확인할 것 — 바로 프로덕션에 올릴 수 있는가

**2023년 11월 13일 이후에 만든 개인 개발자 계정**은
**프로덕션에 바로 못 올린다.** 먼저 이걸 통과해야 한다.

| 요건 | 값 |
|---|---|
| 테스터 수 | **12명 이상** (참여를 *선택한* 사람 기준) |
| 기간 | **14일 연속** |
| 트랙 | **비공개 테스트** |
| 그 다음 | 대시보드에서 **프로덕션 신청** → 검토 보통 7일 이내 |

중간에 참여를 취소한 테스터는 산정에서 빠지고, 다시 들어와도 **14일을 새로 센다.**
학교·직장 구글 계정(워크스페이스)은 테스터로 쓸 수 없다.

### 내 계정이 해당되는지 확인

콘솔 대시보드에 **"프로덕션 신청"** 또는 비공개 테스트 안내가 뜨면 해당된다.
없으면 바로 프로덕션으로 가면 된다.

> 조직(사업자) 계정은 이 요건이 없다. 개인 계정만 해당된다.

### 해당된다면 — 경로가 이렇게 바뀐다

§1 ~ §4 (앱 설정·등록정보)는 **똑같이** 하고,
§5 에서 트랙만 **프로덕션 → 비공개 테스트**로 바꾼다.

```
비공개 테스트 생성 → 테스터 12명 모으기 → 14일 대기
   → 프로덕션 신청 → 검토 7일 → 프로덕션 출시
```

**테스터 12명을 먼저 확보해 두는 게 실질적인 병목이다.**
가족·친구·지인의 개인 Gmail 주소를 모으면 된다. 이메일 목록으로 등록하거나
구글 그룹을 만들어 쓴다.

<sub>※ 인터넷에 "20명"으로 적힌 글이 많은데 **현재 공식 기준은 12명**이다.
도입 초기 숫자가 그대로 돌아다니는 것이다.</sub>

### 2-5. 데이터 보안 ★★ — 가장 까다로운 곳

**앱 콘텐츠** → **데이터 보안** → **시작**

> 예전에 "데이터 세이프티"로 불리던 그것이다.

#### 이 앱의 실제 상황부터

| | |
|---|---|
| 앱 자체의 네트워크 통신 | **없다.** `fetch`/`axios` 호출이 코드에 한 줄도 없다 |
| 학습 기록 | `AsyncStorage` — **기기에만** 저장. 서버로 안 보낸다 |
| 데이터를 모으는 주체 | **AdMob SDK 하나뿐** |

APK 최종 매니페스트에 `com.google.android.gms.permission.AD_ID` 가
머지돼 있는 것을 확인했다. 즉 **광고 ID를 수집한다**고 답해야 한다.

#### 화면 순서대로

**① 개요** → 읽고 **다음**

**② 데이터 수집 및 공유**

> **예** 선택

앱 자체는 안 보내도 **SDK 가 보내는 것도 포함**해야 한다. AdMob 이 보낸다.

**③ 보안 관행**

| 질문 | 답 | 이유 |
|---|---|---|
| 전송 중 암호화되나요? | **예** | Google Mobile Ads SDK 는 TLS 로 전송한다 (구글 공식 문서 명시) |
| 데이터 삭제 요청 방법을 제공하나요? | **예** | 앱 안에 "처음부터 다시 외우기"(기록 삭제)가 있고, 광고 ID 는 안드로이드 설정에서 사용자가 직접 재설정·삭제할 수 있다 |

**④ 데이터 유형 선택**

AdMob SDK 가 수집·공유하는 네 가지를 고른다.

| 카테고리 | 체크할 항목 |
|---|---|
| **위치** | 대략적인 위치 |
| **앱 활동** | 앱 상호작용 |
| **앱 정보 및 성능** | 진단 |
| **기기 또는 기타 ID** | 기기 또는 기타 ID |

<sub>IP 주소로 대략적 위치가 추정되므로 "대략적인 위치"가 들어간다.
정확한 위치는 아니다. 개인정보·금융정보·메시지·사진·연락처는 **전부 체크하지 않는다** —
이 앱은 그런 걸 건드리지 않는다.</sub>

**⑤ 유형별 세부 질문** — 네 항목 모두 **같은 답**이다

| 질문 | 답 |
|---|---|
| 수집 / 공유 | **둘 다** (수집됨 + 공유됨) |
| 일시적 처리인가 | **아니요** |
| 필수 / 선택 | **필수** |
| 수집 목적 | **광고 또는 마케팅**, **분석**, **사기 방지, 보안 및 규정 준수** |
| 공유 목적 | 위와 동일 |

<sub>"공유"는 구글(광고 네트워크)로 나간다는 뜻이다. 광고를 넣은 이상 피할 수 없다.
"필수"인 이유 — 사용자가 광고 데이터 수집만 끄는 선택지를 앱이 제공하지 않기 때문이다.
선택사항으로 선언하려면 모든 사용자가 거부할 수 있어야 한다.</sub>

**⑥ 미리보기** → 사용자에게 보일 화면 확인

**⑦ 제출**

> 확신이 안 서면 **초안으로 저장**해 두고 나중에 고쳐도 된다.
> 제출 후에도 수정 가능하다.
