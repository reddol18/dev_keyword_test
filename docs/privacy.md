# 개인정보처리방침 — 용어먹는하마

최종 수정: 2026년 11월 16일

**용어먹는하마**(이하 "앱")는 사용자의 개인정보를 수집하지 않습니다.
이 문서는 앱이 다루는 데이터와 그 범위를 설명합니다.

---

## 1. 앱이 수집하지 않는 것

앱은 다음을 **수집하지도, 전송하지도 않습니다.**

- 이름, 이메일, 전화번호 등 신원을 알 수 있는 정보
- 계정·로그인 정보 (앱에 로그인 기능이 없습니다)
- 위치 정보
- 연락처, 사진, 파일, 카메라, 마이크
- 사용 기록·분석 데이터

앱에는 회원가입이 없고, 개발자가 운영하는 서버가 없습니다.

## 2. 기기에만 저장되는 것

학습 진도(어떤 단어를 언제 맞혔는지, 다음에 언제 다시 보여줄지)는
**사용자 기기 안에만** 저장되며 외부로 전송되지 않습니다.

- 개발자는 이 기록을 볼 수 없습니다.
- 앱을 삭제하면 이 기록도 함께 삭제됩니다.
- 안드로이드 자동 백업이 켜져 있으면, 구글 계정의 백업에 포함될 수
  있습니다. 이는 구글이 제공하는 기능이며 구글의 개인정보처리방침을
  따릅니다.

학습 자체는 인터넷 연결 없이 동작합니다.

## 3. 광고

앱은 구글 **AdMob**을 사용해 배너 광고 하나를 표시합니다.
결과 화면에만 나타납니다.

광고를 제공하기 위해 AdMob이 다음을 수집·사용할 수 있습니다.

- **광고 ID**(Advertising ID) — 기기에 부여된 재설정 가능한 식별자
- 기기 정보, 대략적인 위치(IP 기반), 광고 상호작용 기록

이 데이터는 구글이 수집하며, 개발자는 접근하지 않습니다. 자세한 내용은
구글의 정책을 따릅니다.

- 구글 개인정보처리방침: https://policies.google.com/privacy
- 구글 광고 데이터 사용: https://policies.google.com/technologies/partner-sites

### 광고 추적을 끄려면

안드로이드 설정에서 직접 끌 수 있습니다.

> 설정 → 구글 → 광고 → **광고 ID 삭제**

이 경우에도 광고는 계속 표시되지만, 관심사 기반 맞춤은 적용되지
않습니다.

## 4. 인터넷 권한을 쓰는 이유

앱은 `INTERNET` 권한을 요구합니다. **광고를 불러오기 위한 용도이며,
그 외에는 사용하지 않습니다.** 학습 데이터는 네트워크로 나가지 않습니다.

기기를 비행기 모드로 두어도 앱의 모든 학습 기능이 동작하며, 이때는
광고 영역이 표시되지 않습니다.

## 5. 아동 대상 여부

이 앱은 IT 실무·면접 용어를 다루며 **만 13세 미만 아동을 대상으로
하지 않습니다.** 개발자는 아동의 개인정보를 의도적으로 수집하지
않습니다.

## 6. 변경

이 방침이 바뀌면 이 문서의 '최종 수정' 날짜를 갱신합니다. 중요한
변경이 있을 경우 앱 업데이트 설명에 함께 안내합니다.
